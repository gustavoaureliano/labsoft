# Logos Academy

Protótipo inicial da interface da Logos Academy.

## Requisitos

- Node.js 24
- npm

## Comandos

- `npm install`: instala as dependências.
- `npm run dev`: inicia o ambiente de desenvolvimento.
- `npm run lint`: verifica o código.
- `npm run build`: gera a versão de produção.
- `npm run test:e2e`: executa o teste Selenium em Chromium, com a aplicação já iniciada em `http://localhost:3000`.

Para executar o teste, inicie a aplicação com `npm run dev` em um terminal e rode `npm run test:e2e` em outro. O botão da videoaula apenas alterna entre os ícones de reproduzir e pausar nesta demonstração; ainda não há um vídeo.
